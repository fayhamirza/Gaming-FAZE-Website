This is a group project from the course "Web Systems" in the Bacehlor's Degree of Information Technology in Networking and Security from Ajman University.

Our group of 5 members, Fayha Mirza - Zunairah Tariq - Alisha Rizwan - Eman Bari, created a gaming website which we named Gaming FAZE. The name uses our initials and plays around with the phrase, "Gaming Phase". 

Our website consists of a number of webpages that display our interactive features and striking design. The purpose of the project was to create a website that leads to several webpages and to build an attractive interface. To not exceed the context of the course, we chose not to make the website fully functional with a database.
